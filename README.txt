# Sudoku Streamlit App

## Overview
This is an interactive Sudoku game built with Streamlit.  
It generates random Sudoku puzzles, displays them in a clean grid layout, and allows users to fill in the blanks directly in the browser.  
Numbers are color‑coded for better visibility, and you can regenerate puzzles, check your solution, or download the current board.

## Features
- 🎲 Random Sudoku puzzle generation
- 🖊️ Interactive input fields for empty cells
- 🎨 Color‑coded fixed clues (red for 1/7/9, blue for 4/6, black for others)
- 🔄 "Generate New Game" button to refresh with a new puzzle
- ✅ "Check Solution" button to validate your entries against Sudoku rules
- 💾 "Download Board" button to save the current puzzle as a text file
- Clean, aligned grid layout using HTML tables

## Requirements
- Python 3.8+
- Streamlit

Install dependencies:
pip install streamlit
